Core Outreach Safety Policies

1. Duplicate Prevention A confirmed successful send permanently blocks any subsequent emails to the same recipient in that campaign.
2. Uncertain Outcome Lock If a transmission times out, it is logged as UNCERTAIN and locked. Automatic retry is strictly blocked.
3. Human Approval Mandate Every draft must be explicitly approved. Unapproved drafts are blocked at the sender level.
